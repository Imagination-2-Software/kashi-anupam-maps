# Kashi Anupam Hotel — Luxury Mobile Landing Page

A premium, elegant, mobile-only landing page for **Kashi Anupam Hotel** (Varanasi, India), designed with a warm beige and deep black luxury aesthetic.

## ✨ Features & Highlights

- **Palette**: Warm Beige / Ivory (`#F3EBDD`) background with Deep Black (`#171717`) buttons & contrast typography.
- **Typography**: Editorial serif headings (`Playfair Display`), delicate cursive accents (`Cormorant Garamond`), and clean, legible body text (`Inter`).
- **Mobile-First Layout**: Strictly optimized for 360px–430px mobile viewport widths (with safe area and centered showcase wrapper on larger desktop displays).
- **Action Buttons**:
  1. **VISIT PROPERTY** → `https://maps.app.goo.gl/saCRNu5KNppQkgSA9?g_st=ac` (Google Maps Live Location)
  2. **HOTEL WI-FI** → Interactive Sheet (Direct QR Code, 1-Tap SSID Copy `KASHI ANUPAM`, Open Network Guide)
  3. **CALL NOW** → `tel:+919580067575` (Direct phone dialer)
  4. **WHATSAPP NOW** → `https://wa.me/919580067575?text=Hello%20where%20is%20this%20hotel%20located%3F` (Pre-filled location inquiry)
  5. **INSTAGRAM** → `https://www.instagram.com/kashi_anupam_hotel?hvrq=MXc3MDFlNWx0czVxZw==`
  6. **VISIT WEBSITE** → `https://kashianupamhotel.com/`
- **Subtle Luxury Accents**: Monogram emblem (`KA`), micro-badges, ambient hotel room preview with 5-star badge, and tactile touch feedback.
